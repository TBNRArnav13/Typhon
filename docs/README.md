# Typhon Product Documentation

This directory contains technical specifications, user guides, and architecture references for the **Typhon Intrusion Detection System**.

---

## Documents

1. **`1_User_Manual.md`**:
   Operational user manual detailing setup, configuration, CLI execution modes, PCAP/CSV parsing, and alert interpretations.

2. **`2_Technical_Documentation.md`**:
   In-depth engineering documentation covering the ingestion pipeline, 33-feature flow extraction, normalizer parameters, and model contracts.

3. **`Typhon_Pipeline_Architecture.drawio`**:
   System architecture diagram in editable Draw.io format detailing the interactions between the CT-DGNN, ST3 AutoEncoder, XGBoost baseline, and the DQN RL-Fusion Engine.

4. **`Unified_DoS_DDoS_XGBoost_Kitsune_PRD.txt`**:
   Product Requirements Document (PRD) detailing baseline security specs, operational thresholds, and detection boundaries.
